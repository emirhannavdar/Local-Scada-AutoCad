    KURULUM YARDIMCISI
    
  
    Register haritası
    Sinyal sözlüğü: Ne ölçülüyor? Ad, birim, veri tipi ve kayıt politikası. Register haritası: Bu ölçüm cihazın hangi adresinden, hangi FC ve veri sırasıyla okunuyor? Çok sayıda ölçümü JSON ile tek seferde tanımlayabilirsin.
    SinyalPDU adresiFCVeri tipiAdetWord / byteÇarpan önerisi
    
  
    JSON ile toplu register haritası
    Dosya seç veya JSON yapıştır. Eksik sözlük tanımları oluşturulur; mevcut sinyaller adlarıyla eşleşir. Aynı harita kaydı atlanır. En fazla 1000 satır / 2 MB.
    Politika seçimi yalnızca cihaz tipi, alarm/okuma/arşiv sınıfı, periyot ve gösterim biçimi gibi ortak alanları doldurur. Birim ve minimum/maksimum JSON’daki her ölçüme aittir. JSON değerleri ortak politikadan önceliklidir. Alarm sınıfı tahmin edilmez; çalışan bir sözlük kaydını seç veya JSON’da geçerli değeri belirt.
    Adresler PDU adresidir. FLOAT32 = 2, FLOAT64 = 4 register otomatik belirlenir. Seçili profil mevcut cihazlarda kullanılıyorsa yeni harita, kurulu registerları değiştirmez. İçe aktardıktan sonra cihaz için “Profilden okuma kurulumu”nu çalıştır.
    SatırSinyalAdresFCTip / adetÇarpanSözlükSonuç
    Mevcut API kayıtları sırayla oluşturur; işlem tek veritabanı işlemi değildir. Hata olursa tamamlanan kayıtlar korunur. Yeniden önizleme yaparak kalan kayıtları ekleyebilirsin.
    
  
    Çarpanlar ve ölçüm birimleri
    Uygulanan değer = çözülen ham ölçüm × register çarpanı. Tag ve saha çarpanı ikinci kez uygulanmaz. W → kW: 0.001; CT/PT toplam oranını gerçek cihazına göre belirle. Birim değişirse bağlı tag’lerin birimi de kaydedilir.
    Değiştireceğin satırları soldan işaretle. Önizleme son API değeri ve mevcut çarpandan tahmin edilir; ham Modbus ölçümü değildir.
    SeçRegisterEski çarpanYeni çarpanHedef birimTahmini önizleme
    
  
    Bağlantı ayarları
    Arayüz yalnızca REST API’ye bağlanır. Modbus ve PostgreSQL bağlantısı backend/collector tarafında kalır.
    Gelişmiş · token ile bağlantıToken yalnızca bu sekmenin belleğinde tutulur. Normal girişte bu alanı doldurman gerekmez.
    API hesabı ile giriş
    Token girmen gerekmez. İlk hesabı API bilgisayarında oluştur; sonraki girişlerde kullanıcı adı ve şifre kullan. Oturum 8 saat geçerlidir.
    Ölçüm birimi cinsindedir. Register okuma periyodunun 3 katı + 2 sn, eski veri eşiği için alt sınırdır.
    
  
    Akış sinyalini eşleştir
    Akım büyüklüğü tek başına yön bilgisi vermez. Eşleştirmeler bu bilgisayardaki tarayıcıya kaydedilir; cihazlara komut gönderilmez.
